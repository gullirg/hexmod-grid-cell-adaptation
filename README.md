# Firing rate adaptation in grid cells produces hexadirectional modulation

Analysis code for Reggio, Kim, Ji, Bush, Barry and Burgess, *Firing rate adaptation in grid cells produces hexadirectional modulation* (submitted).

> **Status:** this repository is being prepared. The analysis code, environment file and step-by-step instructions will be added here.

## Data

The analyses use 3,938 grid cells from six published rat datasets. Four datasets, together 3,759 of the 3,938 cells (95%), are publicly available and can be downloaded from the sources below. Vollan et al. (2025) alone provides 3,724 cells.

| Dataset | Cells | Source | Licence |
|---|---|---|---|
| Vollan et al. (2025) | 3,724 | EBRAINS, https://doi.org/10.25493/R5FR-EDG | CC BY-SA 4.0 |
| Hafting et al. (2005) | 23 | NIRD Research Data Archive, https://doi.org/10.11582/2017.00017 | CC BY 4.0 |
| Sargolini et al. (2006) | 7 | NIRD Research Data Archive, https://doi.org/10.11582/2017.00019 | CC BY 4.0 |
| Brun et al. (2008) | 5 | NIRD Research Data Archive, https://doi.org/10.11582/2018.00015 | CC BY 4.0 |
| Barry et al. (2012) | 118 | Not publicly available; available from the original authors on request | |
| Ólafsdóttir et al. (2016) | 61 | Not publicly available; available from the original authors on request | |

The raw data are not redistributed here. Instructions and scripts to download the public datasets and to reproduce the analyses will be added to this repository. When using these data, please cite the original papers and the dataset records listed above.
